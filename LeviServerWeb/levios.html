LeviOS Web Emulator

Welcome to the web-based emulator for LeviOS, a 16-bit x86 operating system built entirely from scratch in Assembly.

Type help into the terminal once it boots up to see a list of all available commands.


Controls for the programs:

  • Pong — Player 1: W/S keys, Player 2: I/K keys, Escape: Quit
  • Ball — Escape: Quit
  • Fbird — Any key: Flap (Quit upon game over)
  • Snake — WASD: Move, Escape: Quit

Want to build and run LeviOS locally? Check out the repository for all the files you need to download and instructions in the README file.
